## What changed

**12 new tool modules ported from upstream** with a systematic rename
(`sisyphus`→`openbioacademia`, `SISYPHUS_DIR`→`OPENBIOACADEMIA_DIR`,
`bin/sisyphus`→`bin/academica`, `argahv`→`jzhangc`,
`Sisyphus Academica`→`OpenBioAcademia`):
`net, settings, textutil, patterns, reviews, stats_audit, voice, novelty,
workspace, gates, build, agents`.

**Two tool modules replaced** with upstream's richer versions (jz_exp's
urllib-only versions discarded):
`citation_verifier.py` (304→649 ln, adds `verify_references`,
`load_references`, `bibtex_from_doi`, `summarize`, `parse_bibtex`,
`parse_thebibliography`) and `literature_client.py` (290→482 ln, adds
`merge_corpus`, retry via `net`, `.env` integration).

**CLI rewritten** (`src/openbioacademia/cli.py`): 5 → 14 subcommands
(`demo, configure, search, verify, bibtex, new, corpus, refs, voice,
novelty, check, gate, status, build`). `configure.py` fixed: the pre-existing
`test_configure_command_runs` stdin-capture failure is gone (uses an
`isatty()` guard). `__init__.py` got a `__path__` shim so
`openbioacademia.tools` resolves in a plain checkout (no-op in a pip install).

**Launcher + installer.** New `bin/academica` shell launcher (
`PYTHONPATH=$DIR/src exec python3 -m openbioacademia.cli "$@"`).
`install.sh` now installs it to `~/.local/bin`, renders agents via
`python3 tools/agents.py --dest … --opencode-config …`, and validates both the
launcher and the 25 rendered agents.

**25 agent prompts + 16 skill SKILL.md files re-wired** to the gated CLI.
They now use `{{OPENBIOACADEMIA_DIR}}/bin/academica` placeholders (rendered at
install time) and reference the five quality gates and the stage handoff
commands. The em-dash count dropped from 120 to 0 (a side benefit of taking
upstream's em-dash-free prompts verbatim).

**Config, templates, tests, demo.** `config/agent-config.json`: added the 8
missing agents (`gap-analyzer, methodology-designer, data-engineer,
pragmatist, ethicist, competitor, student, dreamer`) and a top-level
`default_model` so `agents.py::model_for` no longer raises.
`templates/{iclr,icml}/template.tex` re-added, and
`templates/{arxiv,neurips,nature}/template.tex` replaced with upstream's
`<<section>>`-token versions (required by `build.py` and by
`test_pipeline.py::test_templates_have_matching_sections`).
Six test files re-added: `test_agents, test_patterns, test_pipeline,
test_settings, test_stats_audit, test_voice_reviews`.
`tests/conftest.py` replaced with upstream's rich version (`offline`,
`isolated_repo`, `demo_run`, `fake_api` fixtures).
`src/openbioacademia/demo_run/` (26 files) re-added.
`src/openbioacademia/demo.py` replaced: now runs the five gates on the
bundled example paper instead of printing a hardcoded demo.

**Lint config.** `.flake8` restored from upstream (`max-line-length=100`,
`extend-ignore=E203,W503`); `pyproject.toml` flake8 `ignore` gained `W503,W504`.
`tools/workspace.py:320` shortened one character so a line that became 101
chars after the `sisyphus`→`academica` rename passes the 100-char limit.
`tests/test_citation_verifier.py`: added a `venue: "Journal of Testing"` to
one bibtex test so the assertion `bib.startswith("@article{")` matches
`generate_bibtex`'s actual contract (no venue → `@misc{}`).
